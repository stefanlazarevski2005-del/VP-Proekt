# VP-Proekt
Репозиториум за Проектот по Визуелно Програмирање. Имплементација на играта Балатро

1. Дизајн на играта, Логика за Карти, Шпил и Рунда.
2. Додавање дизајн на карти, селектирање карти за рака, и анимација за поставување рака.
3. Пресметување на сите раце.
4. Додавање на функција Играње рака и Отфрлување рака / Обновување на анимација.
5. Поврзување UI со функциите на играта, Индекс на раце додаден.
