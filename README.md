# Балатро
Балатро е игра инспирирана од оригиналната игра Balatro, во која играчот треба да гради покер-раце за да добива поени. Секоја рунда има граница која треба да се надмине за да се продолжи во следната рунда. По секоја рунда се преминува во маркет, каде што играчот може да купи специјални карти кои му помагаат да го зголеми бројот на поени што може да ги добие. За да се победи играта, потребно е да се победат 20 рунди.

# Упатство за играње
За да ја почнете играта одете во

`Balatro -> bin -> Publish -> Balatro.exe`

Отворете го `Balatro.exe` фајлот и играјте.

(Опомена: Ако играте на лаптоп, ќе треба да смените Settings на Display)

`System -> Display -> Scale and Layout -> 100%`


# Правила
1. Добиваш 8 карти во рака.
2. На почеток добиваш 4 раце (играње) и 3 отфрлувања,
3. Вредноста на комбинација (Flush, Two Pair, Straight etc) е составена од поени (синото квадратче) и множител (црвеното квадратче). Вредностите на сите комбинации можат да се видат во "Индекс на раце" копчето.
4. Копчето "Играј" ги игра сите карти кои важат во комбинацијата (пр, ако селектираш 2 тројки и еден Ас, само тројките се важат во комбинацијата) и ги додава нивните вредности. Откако се изиграни картите, тие се отфрлуваат и нови карти се додадени од шпилот.
5. Копчето "Отфрли" ги вади картите од вашата рака, и се додаваат нови карти од шпилот.
6. Ако ги потрошиш сите раце (играње) без да ја надминеш границата, ја губиш играта.
7. После секоја рунда играчот добива $3 за победата, $1 за секоја неискористена рака и $1 за секои $5 што ги поседува, до максимум $5.
8. Во маркетот можеш да купиш два вида на карти: Џокери и Планет карти (од планет пакети).
9. Џокери се специјални карти кои имаат уникатен ефект кон играта. Тие можат да: даваат повеќе пари, зголемат поени и множител, го менуваат шпилот итн. Секој Џокер има свој уникатен ефект.
10. Смееш да држиш максимум 5 Џокери.
11. Можеш да ги продадеш џокерите што ги поседуваш.
12. Ефектите на џокерите работат од лево кон десно, така што редоследот на џокерите може да ја смени целокупната вредност на комбинација. Редоследот може да се смени со "Смени Редослед" копчето.
13. Во маркетот не може да се појават дупликати од џокери.
14. Планет карти се карти кој ја зголемуваат вредноста на одредена рака (Flush, Two Pair, Straight...).
15. Планет карти можат да се купат само од Планет пакетите.
16. Во маркетот можеш за $5 да вртиш пак за да добиеш различни џокери во маркетот. После секое вртење се зголемува цената.

# Решениe и Имплементација

Оваа игра е програмирана со Објектно-ориентиран дизајн и применува повеќе ООП-принципи. Класата `Card` претставува апстракција и дефинира заеднички својства и методи за сите карти, додека `PlayingCard` и `Joker` ги наследуваат својствата од `Card` и ги прошируваат нивните функционалности. Преку полиморфизам, методите како `DrawCard()` и `ContainsPoint()` имаат различна имплементација зависно од типот на картата, а `virtual` методите кај `Joker` овозможуваат секој специфичен Џокер и Планет карта да има сопствено однесување.

```
Card
├── PlayingCard
└── Joker
    └── Специфични Joker класи
    └── Специфични Планет класи
```
## Опис на класите PlayingCard и Joker

### PlayingCard

Класата `PlayingCard` претставува обична карта за играње и ги содржи следните својства:

- `suit` – Знакот на картата.
- `number` – Бројот на картата (Ас = 1, Крал = 13).
- `points` – Вредноста на картата (Ас = 11, Крал, Дама и Џандар = 10, а останатите карти имаат вредност еднаква на нивниот број).
- `isPlayable` – Одредува дали картата учествува во избраната покер-комбинација. Вредноста се одредува во методот `CalculateHand()`.

### Joker

Класата `Joker` претставува базна класа за Џокерите и Планет картите.

Содржи својства кои одредуваат **кога се активира ефектот на Џокерот**:

- `BeforeRound` – Ефектот се активира пред почетокот на рундата.
- `PerCard` – Ефектот се активира по секоја изиграна карта.
- `PerHand` – Ефектот се активира по секоја изиграна рака.
- `AfterRound` – Ефектот се активира по завршување на рундата.

Класата `Joker` содржи и виртуелни методи кои овозможуваат секој специфичен Џокер да има различно однесување:

- `Condition(Round round)` – Го проверува условот за активирање на Џокерот. Доколку нема специфичен услов, методот враќа `true`.
- `Effect(Round round, Form1 form)` – Го извршува ефектот на Џокерот.
- `Effect()` – Го извршува ефектот на Планет картата.
- `UpdateCopyBehavior()` – Се користи кај `FinkiZgrada` џокерот за копирање на ефектот на Џокерот кој се наоѓа десно од него.

## Рунда
### Главната игра е организирана околу `Round` класата, која чува податоци за:

- `List<PlayingCard> deck` - Шпилот на сите карти
- `List<PlayingCard> hand` - Картите што можат да се селектираат
- `List<PlayingCard> selected` - Сите карти селектирани од играчот 
- `int hands` - Колку раце (играње) имаш
- `int discards` - Колку отфрлувања имаш
- `int money`- колку пари имаш
- `int handsize` - колку ти е голема раката (стандардна големина 8, освен ако имаш `Корупција` Џокерот или шпилот нема доволно карти да исполни 8)

## Тек на една рунда:
- На почетокот се креира `Round` и се поставуваат почетните вредности.
- Играчот добива 8 карти од deck преку методот `LoadHand()`.
- Играчот избира карти од својата рака. При секоја промена на селекцијата, методот `CalculateHand()` се извршува за да ја одреди моменталната покер-комбинација.
- Со притискање на копчето „Играј“, се играат картите што се означени како `isPlayable`.
- Се пресметуваат поените од играните карти и комбинацијата се додава на вкупниот резултат.
- Играните карти се отстрануваат, а нови карти се земаат од шпилот.

## CalculateHand()

Овој метод ја одредува комбинацијата од сите селектирани карти. Прво, функцијата проверува дали бројот на селектирани карти е 0; доколку нема селектирани карти, веднаш враќа празен резултат. Потоа ги подредува картите според нивната вредност и проверува дали формираат `Straight`, `Flush` или `Royal Flush`. При проверувањето на `Straight`, Асот е посебен случај бидејќи може да се користи и како најниска карта во комбинацијата A, 2, 3, 4, 5, и како највисока карта во комбинацијата A, K, Q, J, 10. За `Royal Flush`, функцијата прво проверува дали картите формираат `Flush`, а потоа ја проверува нивната вкупна вредност. Доколку вкупниот број на поени е 51, комбинацијата се препознава како `Royal Flush`, бидејќи тоа одговара на вредностите на A, K, Q, J, 10. 
Доколку не е пронајден Straight или Flush, картите се групираат според нивниот број. При проверката се користат променливите `three` и `two`. Променливата `three` се поставува на `true` кога постои група од три карти со ист број, додека `two` се поставува на `true` кога постои пар. Променливата `counter` го брои бројот на пронајдени парови. Врз основа на овие вредности се разликуваат `Four of a Kind`, `Full House`, `Three of a Kind`, `Two Pair` и `Pair`. За групите со најмалку две карти, нивните карти се означуваат како `isPlayable`, со што се одредува кои карти учествуваат во комбинацијата. Ако не е пронајдена ниту една од овие комбинации, функцијата враќа `High Card`.

```
public string CalculateHand()
        {
            if (selected.Count == 0)
            {
                return "";
            }
            bool flush = true;
            bool straight = true;
            if (selected.Count != 5)
            {
                flush = false;
                straight = false;
            }
            string f = "Flush";
            string s = "Straight ";
            string hand = "";
            int rf = 0;
            PlayingCard.znak testsuit = selected[0].suit;
            Dictionary<int, List<PlayingCard>> combinations = new Dictionary<int, List<PlayingCard>>();
            SortCardsbyNumber(selected);
            for (int i = 0; i < selected.Count; i++)
            {
                selected[i].isPlayable = false;
                if (!combinations.ContainsKey(selected[i].number))
                {
                    combinations.Add(selected[i].number, new List<PlayingCard>());
                }
                combinations[selected[i].number].Add(selected[i]);
                if (selected[i].suit != testsuit && flush)
                {
                    flush = false;
                }
                if (i != selected.Count - 1 && straight)
                {
                    if (selected[i].number == 1)
                    {
                        if (selected[i+1].number != 5 && selected[i + 1].number != 13)
                        {
                            straight = false;
                        }
                    }
                    else if (selected[i].number != selected[i+1].number+1)
                    {
                        straight = false;
                    }
                }
                rf += selected[i].points;
            }
            if (straight)
            {
                foreach (PlayingCard karta in selected)
                {
                    karta.isPlayable = true;
                }
                hand = s;
            }
            if (flush)
            {
                foreach (PlayingCard karta in selected)
                {
                    karta.isPlayable = true;
                }
                if (rf == 51)
                {
                    hand = "Royal Flush";
                }
                else
                {
                    hand += f;
                }
            }

            if (hand != "")
            {
                return hand;
            }
            bool three = false;
            bool two = false;
            int counter = 0;
            foreach (int key in combinations.Keys)
            {
                if (combinations[key].Count >= 2)
                {
                    foreach (PlayingCard karta in combinations[key])
                    {
                        karta.isPlayable = true;
                    }
                }
                if (combinations[key].Count == 4)
                {
                    return "Four of a Kind";
                }
                if (combinations[key].Count == 3)
                {
                    three = true;
                    continue;
                }

                if (combinations[key].Count == 2) 
                {
                    two = true;
                    counter++;
                    continue;
                }
            }
            if (three)
            {
                if (two)
                {
                    return "Full House";
                }
                else
                {
                    return "Three of a Kind";
                }
            }
            if (two)
            {
                if (counter == 2)
                {
                    return "Two Pair";
                }
                else
                {
                    return "Pair";
                }
            }
            selected[0].isPlayable = true;
            return "High Card";
            }
```
